# Release Checklist

## Content and brand

- [ ] Public services remain limited to website design, software development, and social-media management.
- [ ] Project links, status labels, and client names are accurate.
- [ ] Phone, email, domain, and social links are current.
- [ ] No draft language, placeholder copy, or unsupported claims remain.

## Quality

- [ ] Project validator passes.
- [ ] ESLint passes with zero warnings.
- [ ] TypeScript passes without emitting files.
- [ ] Production dependency audit reports no critical vulnerability.
- [ ] Production build completes.

## Responsive review

- [ ] 320–420 px mobile.
- [ ] 768–1024 px tablet.
- [ ] 1280–1920 px desktop.
- [ ] 2560–3840 px large monitor / television.
- [ ] Keyboard navigation and visible focus states.
- [ ] Reduced-motion mode.

## Search and sharing

- [ ] Canonical URLs are correct.
- [ ] Open Graph and Twitter images render.
- [ ] Sitemap and robots routes load.
- [ ] Organization, service, and project structured data validate.

## Operations

- [ ] Contact form delivers from production.
- [ ] Environment variables are configured in the deployment platform.
- [ ] Privacy, terms, and security pages are reachable.
- [ ] Production deployment is reviewed after cache invalidation.
