# Plumbing showcase screenshots

Upload your actual demo captures to this directory, for example `home-desktop.webp`, `services-desktop.webp`, and `home-mobile.webp`.

Add entries to `src/data/plumbing-demo.json` in display order:

```json
{
  "url": null,
  "screenshots": [
    {
      "src": "/images/templates/structure/home-desktop.webp",
      "alt": "Plumbing template homepage with copper pipe navigation",
      "caption": "Home / desktop",
      "width": 1440,
      "height": 960
    }
  ]
}
```

Use the actual image dimensions. Preserve the verified public `url` after deployment. Do not paste the example entry until the real file exists. Empty screenshots use the designed cover; the local interactive preview always remains available. Screenshots must use simple letters, digits and hyphens with a WebP, PNG or JPEG extension.
